# MEHEDIVAI115 - Desktop Taskbar App

এই প্রোজেক্টটি একটি উন্নত Android অ্যাপ্লিকেশন যা আপনার মোবাইলকে একটি ডেস্কটপ অপারেটিং সিস্টেমের মতো করে তোলে।

## 📋 প্রধান ফিচার

### 🪟 উইন্ডো ম্যানেজমেন্ট
- একবারে ১০-১৫টি অ্যাপ চালাতে পারবেন
- উইন্ডোজের মতো রিসাইজ করতে পারবেন
- ড্র্যাগ করে যেকোনো জায়গায় নিয়ে যেতে পারবেন
- Z-Index ম্যানেজমেন্ট (কোন উইন্ডো সামনে থাকবে)

### 📱 অ্যাপ ম্যানেজমেন্ট
- সব ইনস্টলড অ্যাপ অটো ডিটেক্ট করে
- অ্যাপ ড্রয়ার থেকে দ্রুত অ্যাপ খুলতে পারবেন
- মিনিমাইজ/ম্যাক্সিমাইজ ফাংশনালিটি
- অ্যাপ সুইচার

### 🎨 কাস্টমাইজেশন
- ডার্ক থিম সাপোর্ট
- উইন্ডো পজিশন সেভ করা যায়
- টাস্কবার কাস্টমাইজেশন
- ফেভারিট অ্যাপস

### ⚙️ সিস্টেম ফিচার
- ফুল স্ক্রিন ইমার্সিভ মোড
- স্ক্রিন সবসময় অন থাকে
- ব্যাকগ্রাউন্ড সার্ভিস সাপোর্ট
- জেসচার সাপোর্ট

## 🔧 প্রয়োজনীয়তা

- Android SDK 24+ (Android 7.0+)
- Target SDK 34 (Android 14)
- Kotlin 1.8+
- AndroidX Libraries

## 📦 পারমিশন

- `QUERY_ALL_PACKAGES` - সব ইনস্টলড অ্যাপ দেখতে
- `GET_PACKAGE_USAGE_STATS` - অ্যাপ ব্যবহার ট্র্যাক করতে
- `SYSTEM_ALERT_WINDOW` - ওভারলে উইন্ডো এর জন্য
- `INTERNET` - ভবিষ্যতের ফিচারের জন্য

## 🔄 আর্কিটেকচার

### MVVM প্যাটার্ন
- **Model**: AppInfo ডেটা ক্লাস
- **ViewModel**: TaskbarViewModel (স্টেট ম্যানেজমেন্ট)
- **View**: Activities এবং Fragments

### কী কম্পোনেন্ট
- `MainActivity` - মেইন অ্যাক্টিভিটি
- `TaskbarViewModel` - স্টেট ম্যানেজার
- `WindowManager` - উইন্ডো ম্যানেজমেন্ট
- `FloatingWindow` - ফ্লোটিং উইন্ডো উইজেট
- `TaskbarButton` - টাস্কবার বাটন
